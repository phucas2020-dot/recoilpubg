# PUBG Recoil Control

An automatic recoil control tool for PUBG, written in Python. It works by reading mouse state and sending mouse movement events to compensate for weapon recoil.

---

## 📥 Installation & Run

### Requirements
- Windows 10/11 (64-bit)
- Python 3.8+
- **Administrator privileges** (required)
